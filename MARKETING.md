**Title:** I built EasyCalc: A suite of 7 privacy-first, zero-dependency browser calculators. Just shipped a major UI/UX update!

**Body:**
Hey everyone! 👋

I wanted to share a project I've been working on called **EasyCalc**. It's a collection of 7 different calculators (Arithmetic, Scientific, Percentage, Unit Conversion, GWA, Health, and Date & Time) built entirely with pure HTML, CSS, and Vanilla JavaScript.

**What makes it different?**
* **Privacy First:** Absolutely zero analytics, tracking, or external API calls. Everything runs locally in your browser.
* **No Dependencies:** No React, no build steps, no external fonts or libraries.
* **Works Offline:** Just save the HTML files and you're good to go.

**What's New in the latest update?**
* 🎨 **Unified Design System:** Completely overhauled the UI so all calculators now share a sleek, consistent design language matching the main dashboard.
* ✨ **Aesthetics:** Added modern, subtle background gradients to improve the overall look and feel.
* ⚡️ **Performance:** Optimized script loading (moved scripts to the bottom of the body) to make the calculators load virtually instantly.
